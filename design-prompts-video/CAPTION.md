15 prompts. One for every stage of a design project. 🏗️

Comment **DESIGN** and I'll send you the full set.

Save this — it's the whole project lifecycle, from the first client call to the
template you reuse on the next job.

**1. Design Brief**
"Act as a senior architect/interior designer. Help me create a complete design brief for a [project type] project. Include client goals and lifestyle needs, functional requirements, spatial program, style/mood direction, budget range, timeline milestones, and key constraints. Ask clarifying questions if information is missing."

**2. Project Standards Doc**
"Create a project standards document covering preferred material palette guidelines, drawing/documentation conventions, file naming and folder structure, client communication tone, and a quality-check checklist before any deliverable goes out."

**3. Deep-Dive Concept Mode**
"Act as a design concept strategist. Based on this brief [paste brief], generate three distinct concept directions. For each include a one-line big idea, mood/atmosphere, key material and color direction, spatial strategy, and one reference precedent, with reasoning."

**4. Spec-Driven Design**
"Create a full material and finish specification sheet for [room/space type], including flooring, wall finish, ceiling treatment, lighting, hardware, and upholstery. For each item list material name, finish/color code, supplier option, cost range, and maintenance notes."

**5. Space Planning & Client Experience**
"Act as a space planner. Given this program and square footage [paste details], propose a space plan optimizing flow, daylight, privacy zones, and client experience from entry to key destination spaces. Note adjacency reasoning and code considerations."

**6. Construction Documentation Plan**
"Create a construction documentation checklist for [project type] covering floor plans, RCPs, elevations, sections, details, schedules, and MEP coordination drawings. Note scale, sheet numbering, and SD/DD/CD review milestones."

**7. Coordinate with Consultants**
"Draft a coordination request to send to [structural/MEP/lighting] consultant, including project overview, specific coordination items needed, referenced drawings, and requested response deadline, in a professional and concise tone."

**8. Vendor & Materials Database**
"Help me organize a vendor and materials database template with columns for category, vendor name, contact info, lead time, price tier, sustainability rating, and notes on past project use, structured for a spreadsheet or Notion."

**9. Find Code Compliance Gaps**
"Review this project scope and space program [paste details] against typical [jurisdiction] code requirements for [occupancy type]. Flag potential gaps around egress, accessibility, fire rating, and occupancy load to verify with a code consultant."

**10. Resolve a Site Issue Fast**
"Help me draft a clear RFI response for this site issue: [describe issue]. Include a problem summary, resolution options with pros/cons, schedule/cost impact if known, and a recommended path forward."

**11. Final Walkthrough & Punch List**
"Create a final walkthrough and punch list template for [project type], organized by room/area, with columns for item description, trade responsible, priority level, and completion status, plus a client sign-off section."

**12. Clean Up Redundant Drawings**
"Review this drawing set list [paste sheet names/revisions] and identify redundant or superseded drawings to archive. Suggest a cleaned-up, current sheet index organized by discipline and phase."

**13. Clean Revision Notes**
"Help me write a clear, professional revision log entry for this drawing update: [describe changes], including revision number, date, description, reason for change, and affected sheets."

**14. Standards as Guardrails**
"Turn our design standards into a one-page guardrails checklist covering drawing quality, material consistency, client brand alignment, and code basics, for any team member to run through before submitting work."

**15. Reusable Template**
"Take this one-off project process [describe what was done] and turn it into a reusable template or SOP for future projects, including step-by-step instructions, required inputs, and a checklist."
